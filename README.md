# 공동주택관리 해석례

공동주택관리에 관한 **판결 · 질의회신 · 법령해석**을 매주 월요일 오전 9시(한국시간)에 모아 요약하는 웹페이지입니다.

- 카드에서 요약을 보고, 클릭하면 쟁점·판단·이유·관련 조문·실무 시사점·출처를 볼 수 있습니다.
- 자료별 또는 주간 전체를 PDF로 내려받을 수 있습니다.
- 제목·조문·키워드로 검색할 수 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이지 원본 |
| `data/items.json` | 수록 자료 (항목별 출처 URL 포함) |
| `data/meta.json` | 최근 업데이트 일시 |
| `build.py` | `docs/` (GitHub Pages 배포본) 생성 |

자료를 고친 뒤 `python build.py`를 실행하고 커밋하면 GitHub Pages에 반영됩니다.

## 유의사항

요약은 법원·법제처·국토교통부 공개자료와 전문지 기사를 바탕으로 정리한 것입니다. 법적 판단이 필요하면 반드시 각 출처 원문과 현행 법령을 확인하세요.
